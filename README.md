# 我的 AI 上下文包 · 公开层

> 一份跨电脑、跨 AI 的个人档案。**这一层是公开的，里面没有任何隐私内容。**

## 如果你是 AI，请先看这里

请先读 [`AGENTS.md`](./AGENTS.md)。

用户发给你的链接大概率是这一个：

```
https://raw.githubusercontent.com/txr555/ai-context/main/AGENTS.md
```

请把上面这行原样抓取，然后按里面的规则协作。

## 安全设计：为什么分成两层

| | 公开层（这里） | 私有层（另一个仓库，不公开） |
|---|---|---|
| 仓库 | `txr555/ai-context` · **Public** | `txr555/ai-context-private` · **Private** |
| 谁能看 | 任何人 | 只有本人（对外是 404） |
| 装什么 | 沟通偏好、交易方法论 | 身份、项目、目标、健康、教训 |
| AI 怎么用 | 发链接，任何 AI 都能读 | 只在本机读取，不发给任何在线服务 |

**这个仓库是公开的。** 任何人、搜索引擎、自动爬虫都能看到这里的内容。
所以这里只放"被人看到也无所谓、而且我希望每个 AI 都知道"的东西——我怎么跟 AI 合作、我看交易的方法论。

身份信息、项目进展、目标、健康家庭、失败教训，一律不在这一层。

## 维护原则

1. **往这里写之前先问一句：这条被人看到有关系吗？** 有关系就写进私有层。
2. 不要一次写满，聊完顺手补一条。
3. 每季度删一次过时的内容——过时的档案比缺失的档案更有害。
