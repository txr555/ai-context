## 一、扫描流程铁律

MQL5 Freelance 的列表页与详情页都不可全信，必须双读对照：

- **列表页会缓存、漏新单** → 不能只信列表页判断"有没有单"。
- **详情页也会被 CDN 缓存** → 详情页看到的是"保守下限"（可能比实际旧）。
- **双读规则**：列表页 = 新鲜上限，详情页 = 保守下限，两者对照才是真实状态。
- **404 误判**：详情页 404 可能是真缺失，也可能是缓存 / 限流误判，不要急着判定单子没了。
- **编号补探**：列表只给到 N，要补探 `N+1 ~ N+10` 才敢说"没有更多单"——漏探会错过刚发的单。

## 二、品类判据与护城河

按"预算量级 / 竞争密度 / 零件复用率"三轴快速判：

- **代码审计 / 风控模块类** = 顶格接：预算高一个数量级、竞争少一个数量级、100% 通用零件可复用（最省力高回报）。
- **策略 EA 类** = 红海：同质化严重、比价激烈，原则劝退或只接极低价练手。
- **prop firm（自营交易公司）风控壳** = 顶格接：稀缺、近似风控模块需求，护城河高。
- **中文规格 + 风控品类** = 减速带不是墙：语言门槛筛掉部分竞争者，但不是绝对壁垒，别因此放松报价与交付。

## 三、竞标信套路

- **资历一句话带过，绝不附外链**：平台规则 + 信任双考量；外链反而像 spam。
- **分阶段报价**：先交付核心、再加模块，降低甲方一次性决策门槛。
- **挑 1-3 个真实技术隐患做差异化**：证明你真懂这单的技术风险，而不是模板回复——这是中标率的关键变量。
- **表单填写坑**：
  - 切英文输入法再填数字，防全角数字被系统拒。
  - 报价上限被卡时，**当场在 Comments 写真实工期**（而非硬凑低价委屈交付）。
